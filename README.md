# 🗺️ Project Aashray (SIH 26191)

An AI-ML and GIS framework designed to identify hazard-prone habitations, evaluate local carrying capacities, and optimize safe relocation routes. Developed for the _Smart India Hackathon (SIH) — Problem Statement 26191_ under the Ministry of Home Affairs.

---

## 🎯 Problem Statement (PS 26191)

Intelligent Identification of Hazard-Based Red Zones, Carrying Capacity Assessment, and Immediate Relocation Needs for Vulnerable Habitations.

---

## 🚀 Key Features

- _Red Zone Mapping:_ Uses satellite imagery and terrain data to find high-risk landslide and flood zones.
- _Carrying Capacity Assessment:_ Computes resource thresholds using population data and local infrastructure assets.
- _Relocation Optimization:_ ML routing pipeline to identify safe zones and recommend quick evacuation paths.
- _Admin Dashboard:_ Visualizes risk zones (Red, Orange, Green) on an interactive map tracker.

---

## 🛠️ Tech Stack

- _AI / Machine Learning:_ Python, Scikit-Learn, Pandas, NumPy
- _Geospatial Processing:_ GeoPandas, Rasterio, GDAL
- _Frontend & Backend:_ Streamlit / Python-Flask (or React/Node.js)
- _Database:_ PostgreSQL with PostGIS extensions
